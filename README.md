GUIDE SALTA — FRANCÉS PARA GUIAR TURISTAS

Cómo abrir:
1. Descomprimí el .zip.
2. Abrí index.html con Chrome, Edge o Firefox.
3. No necesita servidor ni Internet para el juego y el mapa.
4. La tipografía de Google es opcional: si no hay Internet usa la fuente del sistema.

Pronunciación:
- El juego busca exclusivamente voces instaladas cuyo idioma sea francés (fr-*).
- Si tu sistema no tiene una voz francesa, NO usa una voz española/inglesa como reemplazo.
- Abrí el botón 🔊 de la esquina superior para ver qué voces francesas detectó el navegador.
- En Windows 11 se pueden agregar voces desde Configuración > Hora e idioma > Voz / Idioma y región,
  agregando Francés (Francia) y sus funciones de voz. La ruta exacta puede variar según la versión de Windows.

Archivos:
- index.html: interfaz principal.
- css/styles.css: estilos.
- js/data.js: niveles, preguntas y vocabulario.
- js/audio.js: selección y reproducción de voz francesa.
- js/map.js: posiciones y animaciones del croquis.
- js/app.js: lógica del juego y modales.
- assets/map/salta-centro.svg: mapa ilustrado editable.

Contenido:
- 4 niveles x 10 situaciones.
- Multiple choice, completar e interpretar el mapa.
- Modal de ayuda contextual.
- Modal para explorar lugares.
- Modal de resultados.
- Promenade libre.
- Valijita animada sobre el recorrido.

Nota:
El croquis es didáctico y esquemático. No pretende reemplazar un mapa de navegación real.
